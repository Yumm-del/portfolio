## 📈 金融科技与量化

### 1️⃣ AI 因子实验室 · AI Factor Lab（2026-08）

> 让 AI 在安全约束内挖掘 A 股因子：一句话想法 → 受限 DSL 表达式 → 量化研究标准体检（IC / 分层 / 换手 / IC 衰减）→ 策略回测。38 个白名单算子、解析层结构安全（无 eval/exec）；多重检验采用 Newey-West HAC + BH/BY 双口径校正，91 个内置因子校正后存活 1 个。
>
> 北京大学金融AI智能体创新大赛（方向二：量化投资策略与金融科技工具研发）参赛作品 · MIT 开源

🔗 [代码](https://github.com/Yumm-del/factor-lab) · [在线体验](https://factor-lab-29n3ulxfgehjfbj5phsapi.streamlit.app/)

### 2️⃣ 工银智养仓 · 个人养老金 AI 合规运营平台（2026-09）

> 面向个人养老金「开户热、缴存冷」的存量账户运营问题：自建问卷调研（n=155）显示开户者中 70.4% 未缴存，据此把客户休眠拆解为「不会投 / 不敢投 / 懒得投」三类成因，为客户经理端提供分型、合规内容生成与分级留痕的可运行原型。
>
> 第 17 届「工行杯」全国大学生金融科技创新大赛 · 养老金融方向参赛作品

🔗 [代码](https://github.com/Yumm-del/pension-ai-demo) · [在线体验](https://pension-ai-demo-sciugmwf46wkvwkijcyujf.streamlit.app/)

### 3️⃣ fin-analyzer · AI 金融分析 Agent

> 输入公司名 → 多线程并行检索 + LLM 分析 → 生成含公司概况、近期动态、风险提示、一句话总结的结构化简报。强制来源标注（幻觉防控）与失败优雅降级；并行化使单次分析耗时从 9 秒降至 3 秒。

🔗 [GitHub](https://github.com/Yumm-del/fin-analyzer)

### 4️⃣ stock-analyzer · A 股行业分析工具

> 按行业板块批量拉取全 A 成分股 PE / PB / ROE 等估值与基本面指标，封装「数据获取 → 清洗 → 统计分析 → 可视化 → 报告生成」的完整链路，自动产出图表与 Markdown 研报。

🔗 [GitHub](https://github.com/Yumm-del/stock-analyzer)
