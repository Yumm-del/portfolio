## 📊 AI 产品深度体验报告

> 8 款产品的深度拆解，每篇约 2500-4000 字。点击报告名在线阅读，或下载 PDF 离线查看。如需一份完整总览，[下载作品集总览 PDF](https://raw.githubusercontent.com/Yumm-del/portfolio/master/ai-product-reviews/Yumm-del%20%C2%B7%20AI%20%E4%BA%A7%E5%93%81%E4%BD%9C%E5%93%81%E9%9B%86.pdf)

### 横向对比速览

| 产品 | 定位 | 核心优势 | 主要短板 |
|------|------|---------|---------|
| DeepSeek | 技术开源派 | 推理链透明、开源、性价比 | 多模态与生态较弱 |
| 豆包 | 流量生态派 | 原生场景渗透、分发强 | 深度任务能力一般 |
| 通义千问 | 企业嵌入派 | 阿里生态、B 端集成深 | C 端品牌认知弱 |
| 腾讯元宝 | 连接办公派 | 微信 / 腾讯文档生态 | 独立场景与差异化有限 |
| Kimi | 功能差异化派 | 长文本、产品克制 | 场景窄、生态弱 |
| ChatGPT | 通用 Agent 平台派 | 分发、生态、端到端任务闭环 | 入口边界模糊、Agent 信任与价格分层 |
| Claude Code | 终端 Agent 派 | 长任务、多文件重构、定制层深 | 成本 / 额度、终端学习曲线 |
| Codex | 云端并行 Agent 派 | 云端并行、ChatGPT 分发、沙箱 | 计划漂移、计量不透明 |
